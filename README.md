# Mosaico

Editor web de mosaicos con fotos y vídeos, exportable a MP4. Todo se procesa en el navegador (sin servidor).

- Formatos 1080×1920 y 1920×1080, 26 tipos de mosaico
- Volumen y velocidad por clip, volumen general
- Exportación a MP4 (Chrome/Edge 126+ y Safari; Firefox exporta WebM)

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.
